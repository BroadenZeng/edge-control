# Edge Control

让支持运行本地命令的 AI 助手操作你**正在使用的 Microsoft Edge**：读取网页、打开页面、点击、截图，以及按需管理油猴脚本。它连接现有浏览器，因此可以使用现有的登录状态和扩展；它不会另行启动一个浏览器。

## 开始使用

1. 在 Windows 电脑上下载或克隆本项目，解压后记住文件夹位置。
2. 正常打开 Edge，在地址栏输入 `edge://inspect`。选择 **Remote debugging（远程调试）**，允许当前浏览器实例远程调试。若没有这个选项，可在 `edge://settings/help` 更新 Edge 后再试；单位策略或浏览器配置也可能影响该选项。
3. 在项目文件夹中打开 PowerShell，运行：

   ```powershell
   .\edge_mcp.ps1 -Tool edge_status -Ensure
   ```

   首次运行需要 Node.js 22 或更高版本。如果没有，脚本会尝试使用 Windows 程序包管理器 `winget` 自动安装 Node.js LTS；安装可能需要系统授权，失败时按提示手动安装。安装后可能需要重新打开终端。也可以从 [Node.js 官网](https://nodejs.org/zh-cn/download)手动安装。
4. 如果结果包含 Edge 版本和标签页列表，说明连接成功。若出现调试授权提示，请自行处理。后台服务响应并不代表 Edge 已连接。
5. 把本项目的**实际文件夹路径**告诉有本地命令执行能力的 AI 助手，并让它先阅读其中的 `AGENTS.md` 和 `AI-GUIDE.md`。例如：

   > 请使用我电脑上的 Edge Control 操作当前 Edge。项目文件夹是 `D:\你的路径\edge-control`，请先阅读其中的 AGENTS.md 和 AI-GUIDE.md，然后帮我查看当前网页。

   请将示例路径替换为实际路径。本项目不保证所有 AI 产品都能访问本机文件或执行命令；能否使用取决于你所用的 AI 工具及其授权。

## 可以做什么

- 查看标签页，读取网页内容，打开页面、点击和截图。
- 查看、比对和更新油猴脚本。比对和更新需要指定脚本 ID 和本地文件；更新会重载扩展，默认不刷新网页。
- 按任务需要读取 Cookie、读写本地文本文件或执行本机命令。

工具使用当前 Windows 用户权限，也可能访问 Edge 的登录状态。**只让你信任的 AI 助手或程序使用它**，密码和验证码由你自己输入。

## 常见问题

- **连接失败**：确认 Edge 正在运行、远程调试已开启，并检查是否有等待处理的授权提示。请把具体错误交给 AI 或参考 [AI 操作与排错指南](AI-GUIDE.md)。不要为了重试强制关闭 Edge 或清理数据。
- **Node.js 自动安装失败**：检查 `winget` 是否可用，或从官网下载 Node.js 22 及以上版本。
- **油猴功能不可用**：确认 Edge 已安装油猴扩展和目标脚本；不同版本的扩展可能使用不同的内部存储格式。
- **怎么停止**：手动运行 `start-bridge.cmd` 时，可在其窗口按 Ctrl+C。由 `-Ensure` 启动的后台桥，可查看 `http://127.0.0.1:9333/health` 获取进程 ID 和目录；确认没有其他任务使用后，在任务管理器结束对应 Node.js 进程，不要结束 Edge。

## 权限与运行说明

后台桥默认只监听本机 `127.0.0.1:9333`，**没有调用方身份认证**；本机其他程序仍可能调用它，不要将端口暴露到网络。它会拒绝带浏览器来源标头的请求，但这不能代替身份认证。

`auto-allow-debug.ps1` 是可选脚本，单独运行后会尝试自动点击远程调试授权，正常启动流程不会自动运行它。

- [AGENTS.md](AGENTS.md)：给 AI 助手的操作约定。
- [AI-GUIDE.md](AI-GUIDE.md)：给 AI 助手的调用方法、工具参数和排错指南。

已进行语法和部分本机接口检查；不同 Windows、Edge 和油猴版本下的完整兼容性仍需实际验证。项目当前未附带开源许可证。
