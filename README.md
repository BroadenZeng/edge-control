# Edge Control

让 AI 助手操作你正在使用的 Microsoft Edge：查看网页、点击和填写表单、截图，以及管理油猴脚本。工具使用 Edge 现有的登录状态和扩展。

## 开始使用

1. 在 Windows 电脑上下载或克隆本项目，并记住解压后的文件夹路径。
2. 打开 Edge，在地址栏输入 `edge://inspect`，进入 **Remote debugging（远程调试）**，开启当前浏览器实例的远程调试。如果没有这个选项，请在 `edge://settings/help` 检查并更新 Edge；浏览器管理策略或配置也可能影响该选项。
3. 把项目文件夹路径告诉 AI 助手，让它阅读操作说明并检查连接。例如，将下面的路径换成你的实际路径：

   > 请使用我电脑上的 Edge Control 操作当前 Edge。项目文件夹是 `D:\你的路径\edge-control`。请先阅读其中的 AGENTS.md 和 AI-GUIDE.md，检查连接，然后帮我查看当前网页。

4. 如果 Edge 出现远程调试授权提示，请处理提示。AI 需要登录密码或验证码时，请由你自己输入。

运行需要 Node.js 22 或更高版本。如果电脑没有符合要求的版本，工具会尝试通过 Windows 程序包管理器 `winget` 自动安装 Node.js LTS；安装失败时可从 [Node.js 官网](https://nodejs.org/zh-cn/download)手动安装。

## 可以做什么

- 查看当前网页和标签页，读取页面中的按钮、链接与输入框；点击、填写、等待、滚动、按键、悬停和截图。
- 将指定本地文件交给网页上传；观察下载文件夹中新增的文件。下载观察只能列出候选文件，不能确定文件来自哪个网页或已经下载完成。
- 查看、比对和更新油猴脚本。更新需要明确指定脚本和本地文件，会尝试重载扩展，默认不刷新网页。
- 按需查看网页控制台消息、处理网页弹窗，以及使用本机文件读写和命令执行功能。

页面快照不保证包含 iframe 或所有自定义组件；提交、上传和下载需要根据页面状态或实际文件进一步确认。

## 常见问题

**没有远程调试选项怎么办？** 先检查 Edge 是否有更新，再检查浏览器是否受单位策略或其他设置管理。

**为什么需要点击允许？** Edge 可能在建立远程调试连接时要求授权。项目提供可选的 `auto-allow-debug.ps1`，单独运行时会尝试自动处理此类弹窗；它默认不会自动启动。AI 客户端自己的权限提示由对应客户端管理，该脚本无法替代。

**连接失败怎么办？** 确认 Edge 已打开、远程调试已开启，查看是否有等待处理的授权提示，并把具体错误交给 AI 排查。不要为了重试强制关闭 Edge 或清理浏览器数据。

**Node.js 安装失败怎么办？** 确认 `winget` 可用，或从 Node.js 官网手动安装 22 及以上版本；安装后可能需要重新打开终端。

**油猴功能不可用怎么办？** 确认 Edge 已安装油猴扩展和目标脚本。不同扩展版本的内部存储可能不同；更新后应核对结果。

**怎么停止后台服务？** 手动运行 `start-bridge.cmd` 时，可在其窗口按 Ctrl+C。通过 AI 启动的后台服务，可让 AI 确认没有其他任务使用后停止；不要结束 Edge。

## 使用权限与安全

本工具能够使用当前用户的 Windows 权限，还可能访问已登录的网页及 Cookie。请只交给信任的 AI 助手或程序使用。后台服务默认只接受本机连接，但**没有调用方身份认证**；本机其他程序仍可能调用它，请勿将服务端口暴露到网络。

原有功能已由项目使用者测试；新增网页交互功能已在当前 Edge 的测试页面验证页面识别、填写、选择、点击、等待、文件选择、控制台日志和确认框。不同电脑、Edge 或油猴版本以及真实网站仍可能表现不同。
