# Edge Control

让 AI 助手操作正在使用的 Microsoft Edge，使用现有的登录状态和扩展。

## 开始使用

1. 下载并解压项目，记住文件夹路径。
2. 在 Edge 打开 `edge://inspect`，进入 **Remote debugging（远程调试）**，开启当前浏览器实例的远程调试。
3. 把文件夹路径告诉 AI 助手，例如：

   > 请使用 `D:\你的路径\edge-control` 控制当前 Edge。

4. 首次连接如出现 Edge 远程调试授权提示，请手动点击允许；首次连接成功后，后续重连会尝试自动处理此提示。

运行需要 Windows 和 Node.js 22 或更高版本。缺少合适版本时，工具会尝试通过 `winget` 安装 Node.js LTS；也可从 [Node.js 官网](https://nodejs.org/zh-cn/download)安装。

## 创建本地技能

将下面的话发给 AI 助手，即可让它根据仓库创建本地技能：

> 请根据 https://github.com/BroadenZeng/edge-control 创建本地技能，方便以后控制当前 Edge。

## 功能

- 读取页面、识别元素、点击、填写、等待、滚动、按键和截图。
- 选择本地文件上传、观察下载目录、查看控制台消息和处理网页弹窗。
- 查看、比对和更新油猴脚本。
- 按需读写本地文件、执行命令和读取浏览器 Cookie。

下载观察只能列出目录中的新增文件，不能确认来源或下载是否完成。页面快照可能不包含 iframe 和部分自定义组件；提交和上传后应检查结果。

## 常见问题

- **找不到远程调试选项**：在 `edge://settings/help` 检查并更新 Edge；浏览器策略也可能影响该选项。
- **连接失败**：确认 Edge 正在运行、远程调试已开启，并检查授权提示。将具体错误交给 AI 排查。
- **反复出现授权提示**：首次连接需手动处理。首次成功后，后续重连期间工具会在短时间内尝试自动点击 Edge 的远程调试提示；AI 客户端自身的权限提示不由该脚本处理。如需恢复首次手动授权，让 AI 调用 `edge_auto_reset`。
- **油猴功能不可用**：确认已安装扩展和目标脚本；扩展版本变化可能影响兼容性。

## 权限与资料

工具使用当前 Windows 用户权限，并可能访问浏览器登录状态和 Cookie。只交给信任的助手或程序使用。后台服务只监听本机，但没有调用方身份认证，请勿将端口暴露到网络。自动处理授权仅在重连期间短暂运行，可能同时匹配到其他程序发起的 Edge 远程调试提示。
